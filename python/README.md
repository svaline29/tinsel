# splat

3D scenes drawn as coloured ASCII. A scene is a pile of 3D points; the renderer spins, lights and
projects them, then turns brightness into characters. Runs live in a terminal or exports video.

    pip install numpy pillow          # ffmpeg needed for .mp4
    python3 scenes/tree.py            # live preview (truecolor terminal, Ctrl-C quits)
    python3 scenes/car.py --export car.mp4                 # 1080x1920 vertical
    python3 scenes/car.py --export car.mp4 --size 320x90   # 1920x1080 landscape
    python3 scenes/tree.py --export still.png --at 6       # one frame at t=6s

## Any 3D model, wrapped in lights

    python3 scenes/wrap.py model.obj --export out.mp4
    python3 scenes/wrap.py model.stl --turns 14 --bulbs 400 --color 0.1,0.3,0.9 --palette warm

`.obj` and `.stl` both work. If the model lies on its side add `--up z` (or `--up y`); if it faces the
wrong way add `--yaw 90`. In your own scenes: `fx.wrap_lights(shapes.load_mesh(path, n=150000))`.

## The website (web/index.html)

One self-contained page, no server code, no build step, nothing uploaded. Visitors:

1. pick a built-in model (tree, sports car, crossover, rocket, snowman, gift), type any word to get 3D letters, or drop in their own `.glb`, `.obj` (+ `.mtl`) or `.stl`
2. choose lights (wrapped string / scattered, colours, bulbs, turns) or press "Surprise me"
3. choose a scene: spinning on ice, or driving through snow (ground, snow and pines slide past; built-in cars spin their wheels)
4. optionally keep the build-up intro (model grows from the ground, lights switch on, caption wipes in) and the code panel (the page's own source scrolling underneath)
5. record an MP4 (vertical, square or wide), save a PNG, or copy a link that reopens the same look

Uploaded models keep their own material colours and textures; hidden interior geometry is thrown away
so the visible shell gets all the detail. Draco/Meshopt-compressed `.glb` files are not supported.

To host it, put `web/index.html` on any static host:

    cd web && python3 -m http.server 8000        # try it locally at http://localhost:8000
    # GitHub Pages / Cloudflare Pages / Netlify: upload the file, done
    # your own box: serve the folder with Caddy or nginx

Change the name stamped on every video with the `SITE` constant at the top of the script.
All built-in models are generated by code in the page, so there is nothing to license.

Only use models you are allowed to use. Check the licence on each download (CC0 needs nothing;
CC-BY needs a credit in your caption; "editorial" or "non-commercial" licences are not safe for a monetised account).

## The four ideas

1. **Cloud**: points with position, normal, colour, plus `emit` (glows), `blink`/`phase` (twinkle),
   `shine` (highlights), `glyph` (fixed character), `t0` (appears at time). Add clouds with `+`.
2. **Shapes** (`splat.shapes`) make Clouds: `sphere torus box lathe pine sports_car wheel`,
   `Loft` (cross-sections along a body), `parametric` (any u,v surface), `load_mesh` (.obj / .stl).
3. **Effects** (`splat.fx`): `Stars` `snow` `ground` `lights_on` `light_string` `glow_ball` `spray`
   `scroll_x`, and `Spot` for headlights.
4. **Motion** is two hooks on `scene.add(cloud, xform=..., deform=...)`:
   - `xform(t) -> 4x4 matrix` moves the whole object (spin, bounce, drive): `rot_y(t)`, `translate(...)`
   - `deform(t, P) -> P` moves each point (falling snow, scrolling ground)

## Smallest scene

    from splat import *
    scene = Scene(Camera.orbit(radius=5, height=1.5, target=(0, 1, 0)))
    scene.add(shapes.pine())
    scene.add_backdrop(fx.Stars())
    run(scene)

## Making your own things

| You want                         | Use |
|----------------------------------|-----|
| Round things (rocket, bottle, snowman, planet) | `shapes.lathe([(radius, y), ...])` |
| Long bodies (car, plane, boat, fish)           | `shapes.Loft([(x, half_width, y_bottom, y_top, squareness), ...])` |
| Anything with a real 3D model                  | `shapes.load_mesh("model.obj")` |
| Lights along an edge                           | `fx.light_string(loft.rail(angle)[0])` or `fx.light_string(shapes.polyline(pts, n))` |
| Lights scattered on a surface                  | `fx.lights_on(cloud, n)` |
| Things driving                                 | keep the object still; `fx.ground(speed=v)`, `fx.snow(drift=(-v,0,0))`, `fx.scroll_x(v, ...)` |
| Reflection                                     | `Scene(mirror_y=0)` and `scene.add(obj, reflect=True)` |

Look knobs: `Scene(ramp=" .:-=+*#%@")` (the character set), `glow`, `ambient`, `light`;
`--size` (more, smaller characters = more detail) and `--cell` (pixels per character).
